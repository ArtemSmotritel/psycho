# Додаток Т — Схема навігації інтерфейсу користувача

Навігаційна діаграма (site map) із трьома групами екранів: **Спільні екрани** (до визначення ролі), **Психолог**, **Клієнт**. Прямокутники зі скругленими кутами — екрани; ромб ◇ — точка розгалуження за умовою (без дії користувача); стрілки підписані дією, яка викликає перехід. Побудовано за фактичною структурою маршрутів `frontend/app/routes.ts` та бокового меню `useSidebarItems.ts`.

## Група «Спільні екрани»

Вузли:
1. С1 Головна сторінка (`/`) — початковий екран для будь-кого, хто ще не увійшов у систему; кнопка «Get Started».
2. С2 Вхід (`/login`) — дві картки вибору ролі («Psychologist» / «Client») і кнопка «Continue with Google»; вибір ролі тут лише запамʼятовується (у sessionStorage) і застосовується вже після OAuth.
3. С3 ◇ Обробка входу (`/auth/callback`) — технічний проміжний екран без дій користувача; після підтвердження входу Google система визначає, куди спрямувати користувача, за трьома умовами по черзі: чи є збережений токен запрошення, чи є збережений намір ролі з екрана С2, чи вже відома активна роль з попереднього сеансу.
4. С4 Вибір ролі (`/role-select`) — резервний екран із тими самими двома картками; зʼявляється, лише коли жодна з умов на С3 не визначила роль (наприклад, повторний вхід без збереженого наміру).
5. С5 Прийняття запрошення (`/invite?token=…`) — не має пункту в жодному меню, відкривається лише за посиланням, яке психолог надсилає клієнту окремо.

Звʼязки:
- С1 → С2 : натискання «Get Started»
- С2 → С3 : натискання «Continue with Google» після вибору ролі на картці (проміжно — вхід через Google, поза застосунком)
- С5 → С3 : перехід за посиланням запрошення, якщо користувач ще не увійшов у систему (проміжно — вхід через Google, поза застосунком)
- С5 → К1 : перехід за посиланням запрошення, якщо користувач уже увійшов у систему — запрошення приймається одразу, роль примусово встановлюється «Клієнт»; перетинає межу групи Спільні → Клієнт
- С3 → К1 : якщо перехід відбувався через запрошення (є збережений токен) — перетинає межу групи Спільні → Клієнт
- С3 → П1 : якщо на С2 було обрано роль «Psychologist» — перетинає межу групи Спільні → Психолог
- С3 → К1 : якщо на С2 було обрано роль «Client» — перетинає межу групи Спільні → Клієнт
- С3 → С4 : якщо жодну з умов вище не виконано (роль невідома)
- С4 → П1 : вибір картки «Psychologist» — перетинає межу групи Спільні → Психолог
- С4 → К1 : вибір картки «Client» — перетинає межу групи Спільні → Клієнт

## Група «Психолог»

Кожен екран цієї групи показує постійну бокову панель; вона винесена окремим вузлом, оскільки доступна з будь-якого екрана групи.

Вузли:
1. П0 Бокова панель навігації — пункти меню: Dashboard, Clients, Invitations, Sessions, Associative Images.
2. П1 Дашборд (`/psycho`) — огляд: банер активної сесії (за наявності), три лічильники навантаження, список найближчих сесій, список останніх клієнтів.
3. П2 Клієнти (`/psycho/clients`) — список усіх клієнтів психолога.
4. П3 Профіль клієнта (`/psycho/clients/:clientId`) — картка клієнта з двома вкладками нижче.
5. П3а Прогрес клієнта (`/psycho/clients/:clientId/progress`) — вкладка профілю.
6. П3б Сесії клієнта (`/psycho/clients/:clientId/appointments`) — вкладка профілю, список сесій саме цього клієнта.
7. П4 Деталі сесії (`/psycho/clients/:clientId/appointments/:appointmentId`) — картка однієї сесії.
8. П5 Жива сесія (`/psycho/clients/:clientId/appointments/:appointmentId/live`) — робочий екран під час консультації; доступний лише поки сесія активна.
9. П6 Перегляд вкладення (`/psycho/clients/:clientId/appointments/:appointmentId/attachment/:attachmentId`) — нотатка, рекомендація або враження, повʼязані із сесією.
10. П7 Запрошення (`/psycho/invitations`) — керування запрошеннями для нових клієнтів.
11. П8 Сесії — розклад (`/psycho/appointments`) — повний розклад психолога за всіма клієнтами.
12. П9 Бібліотека асоціативних зображень (`/psycho/associative-images`) — керування зображеннями для вкладень.

Звʼязки:
- П0 → П1, П0 → П2, П0 → П7, П0 → П8, П0 → П9 : пункт бокового меню, доступно з будь-якого екрана групи
- П1 → П5 : натискання «Go to appointment» на банері активної сесії, лише якщо сесія триває
- П1 → П4 : посилання «View» біля найближчої сесії у списку
- П1 → П3 : посилання «View profile» біля останнього клієнта у списку
- П2 → П3 : натискання на клієнта у списку
- П3 → П3а : вкладка «Прогрес»
- П3 → П3б : вкладка «Сесії»
- П3б → П4 : натискання на рядок сесії
- П4 → П5 : перехід до живої сесії, лише поки сесія активна
- П4 → П6 : перехід до вкладення сесії
- П8 → П4 : натискання на рядок сесії або пункт меню рядка «View appointment details» — веде до тієї самої картки сесії, що й П3б
- П8 → П3 : пункт меню рядка «View client profile»
- П6 → П3 : посилання «Open Client Profile» (наявне лише в перегляді психолога)
- П6 → П4 : посилання «Open Session» (наявне лише в перегляді психолога)

## Група «Клієнт»

Вузли:
1. К0 Бокова панель навігації — пункти меню: Dashboard, My Profile, Appointments, Progress.
2. К1 Дашборд (`/client`) — огляд: банер активної сесії (за наявності), список власних психологів, найближча сесія, рекомендації, що очікують реакції, зведення по сесіях.
3. К2 Мій профіль (`/me`) — особисті дані клієнта.
4. К3 Сесії (`/client/appointments`) — список усіх сесій клієнта.
5. К4 Деталі сесії (`/client/appointments/:appointmentId`) — картка однієї сесії.
6. К5 Жива сесія (`/client/appointments/:appointmentId/live`) — робочий екран під час консультації; доступний лише поки сесія активна.
7. К6 Перегляд вкладення (`/client/appointments/:appointmentId/attachment/:attachmentId`) — рекомендація або враження, повʼязані із сесією.
8. К7 Прогрес (`/client/progress`) — горизонтальна стрічка часу з історією сесій.

Звʼязки:
- К0 → К1, К0 → К2, К0 → К3, К0 → К7 : пункт бокового меню, доступно з будь-якого екрана групи
- К1 → К5 : натискання «Join now» на банері активної сесії, лише якщо сесія триває
- К1 → К4 : посилання «View appointment» біля найближчої сесії
- К1 → К3 : посилання «View all appointments»
- К1 → К1 (дія на місці, без переходу) : позначення рекомендації виконаною або залишення коментаря просто на дашборді
- К3 → К4 : натискання на рядок сесії
- К4 → К5 : перехід до живої сесії, лише поки сесія активна
- К4 → К6 : перехід до вкладення сесії
- К7 → К4 : натискання на позначення рекомендації чи враження у стрічці прогресу

Підпис: обидві групи мають однакову глибину переходів — верхньорівневі екрани прямо з бокового меню, картка сесії як проміжний вузол, з якого розгалужуються жива сесія і перегляд вкладення. Єдина точка перетину груп — вхід у систему: після вибору ролі (С2/С4) або прийняття запрошення (С5) користувач потрапляє у відповідну групу, і бокове меню далі показує лише екрани цієї ролі.
