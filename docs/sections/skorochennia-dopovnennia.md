API — прикладний програмний інтерфейс (англ. Application Programming Interface).
JSONB — двійковий формат зберігання даних JSON у СКБД PostgreSQL (англ. JSON Binary).
OAuth — відкритий протокол авторизації, що дозволяє надавати застосункам доступ до ресурсів користувача без передачі пароля (англ. Open Authorization).
PIM — платформонезалежна модель (англ. Platform Independent Model).
REST — архітектурний стиль взаємодії компонентів розподіленого застосунку через HTTP (англ. Representational State Transfer).
SOA — сервіс-орієнтована архітектура (англ. Service-Oriented Architecture).
SPA — односторінковий вебзастосунок (англ. Single Page Application).
UML — уніфікована мова моделювання (англ. Unified Modeling Language).
СКБД — система керування базами даних.
